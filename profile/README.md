## What Is ArgyllCMS

ArgyllCMS is a color-measurement helper for a display or a printer you own or administer in a lab. ArgyllCMS display calibration is the screen path: show patches, read them, and save a profile for that monitor. ArgyllCMS printer profile is the paper path: print ArgyllCMS test chart with fixed driver settings, then measure it. A home desk, a photography class, or a small print corner can keep color closer from one week to the next.

ArgyllCMS patch reading is the careful middle step. The meter has to see the patch it thinks it is reading. ArgyllCMS profile check comes later, when you want to know if the screen or the printer still matches the profile you saved. The work stays on your own devices. You are not adjusting a machine you do not control.

Do the screen first if prints and the monitor disagree and you are unsure which one moved. Run ArgyllCMS display calibration, then print one familiar photo. For the printer, keep the driver settings unchanged, print ArgyllCMS test chart, complete ArgyllCMS patch reading, and build ArgyllCMS printer profile. Use ArgyllCMS profile check after a lamp change, a new paper, or a month of ordinary use.

2. **Calibrate The Screen:** Run ArgyllCMS display calibration and save the profile with a name that includes the monitor.

4. **Read The Patches:** Complete ArgyllCMS patch reading without skipping rows.
5. **Build The Printer Side:** Create ArgyllCMS printer profile from those readings and print one known photo.
